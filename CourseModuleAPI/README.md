Course Query Chatbot Backend

Overview

This ASP.NET Core Web API scrapes course information from https://unitedsofttech.co.in/Courses, stores the data in SQL Server using Entity Framework Core, and exposes REST endpoints including a /api/chat endpoint for course-related natural-language queries. The project is designed so an AI provider can be integrated later via IChatService.

Prerequisites

- .NET 10 SDK
- SQL Server or LocalDB
- Visual Studio 2022/2026 or VS Code
- (Optional) dotnet-ef tools installed globally: dotnet tool install --global dotnet-ef

Required NuGet packages

Run these commands in the CourseModuleAPI project folder:

dotnet add package Microsoft.EntityFrameworkCore.SqlServer
dotnet add package Microsoft.EntityFrameworkCore.Tools
dotnet add package HtmlAgilityPack
dotnet add package Swashbuckle.AspNetCore


Database setup & migrations

1. Update connection string in CourseModuleAPI/appsettings.json to point to your SQL Server instance.

2. Create initial EF migration and apply (from solution root):

dotnet ef migrations add InitialCreate --project CourseModuleAPI --startup-project CourseModuleAPI
dotnet ef database update --project CourseModuleAPI --startup-project CourseModuleAPI

Note: If you don't have dotnet-ef installed, install it with: dotnet tool install --global dotnet-ef

Running the application

- From Visual Studio: set CourseModuleAPI as startup project and run.
- From command line:
  dotnet run --project CourseModuleAPI

On first run the application will apply migrations and automatically trigger an initial scrape if no courses exist in the database. Logs will indicate how many courses were added.

API Endpoints

GET /api/courses
- Returns all courses (with modules).

GET /api/courses/{id}
- Returns course details and modules by id.

GET /api/courses/search?name=python
- Searches courses by name (case-insensitive contains).

GET /api/courses/{id}/modules
- Returns modules for a course.

POST /api/courses/refresh
- Triggers a manual refresh (scrape + upsert).

POST /api/chat
- Body: { "query": "What is the duration of the Python course?" }
- Returns a ChatResponse with answer sourced from the database.

Sample requests (curl)

1) List courses
curl https://localhost:5001/api/courses

2) Chat query
curl -X POST https://localhost:5001/api/chat -H "Content-Type: application/json" -d "{\"query\": \"What courses are available?\"}"

Postman

- Import the above endpoints as individual requests.
- Use POST /api/courses/refresh to re-scrape the website.

Notes and limitations

- Scraper is best-effort and relies on the current structure of the source site; it may require updates if the site's HTML changes.
- ChatService currently uses heuristic intent detection and database content only. An external AI provider can be integrated by implementing IChatService to call provider APIs and passing database content as context.
- Do not expose API keys in source code. Use environment variables or secure secret stores.

Troubleshooting

- If scraping fails due to network/timeout, check logs and ensure the server can reach the target URL.
- If migrations fail, verify connection string and SQL Server accessibility.
